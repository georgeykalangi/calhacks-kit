# Cal Hacks 13.0 event preset

Source: https://www.calhacks.io (checked 2026-10-16). Items marked TBA are announced at kickoff.
This kit is unofficial. When this file and the organizers disagree, the organizers win.

- Venue: Palace of Fine Arts, 3601 Lyon St, San Francisco
- Scale: 2,000+ hackers, 300+ projects, $100K+ in prizes
- Hacking time: 36 hours
- Submission deadline: TBA at kickoff. Ask the team or check the event Discord.
- Judging format: TBA at kickoff.
- Sponsor tracks and prize requirements: TBA at kickoff. Record the ones you target in HACK.md.

## Rules that shape scope
- You cannot work on a project started before the hackathon. Ideation beforehand is allowed;
  all implementation happens during the event.
- Open-source libraries, public APIs, and AI coding tools are normal hackathon practice.
  Disclose what you used in your submission, and ask an organizer if you are unsure.

## Judging themes
Based on publicly available Cal Hacks / Devpost judging themes. Confirm the official rubric at kickoff.

| Criterion | The judge's question |
|-----------|----------------------|
| Application | Is it useful in the real world? Who is it for? |
| Functionality / Quality | Does it work smoothly and feel clear? |
| Creativity | Is the approach original or fresh? |
| Technical Complexity | Was there meaningful engineering behind it? |

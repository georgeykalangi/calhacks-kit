# Cal Hacks 13.0 event preset

Source: https://www.calhacks.io and the hacker guide (checked 2026-10-16). Items marked TBA are
announced at the opening ceremony on October 23. This kit is unofficial. When this file and the
organizers disagree, the organizers win.

- Venue: Palace of Fine Arts, 3601 Lyon St, San Francisco, CA
- Dates: October 23-25, 2026
- Scale: 2,000+ hackers, 300+ projects, $100K+ in prizes
- Hacking time: 36 hours
- Submission deadline: Sunday, October 25. Exact time TBA at the opening ceremony; check the
  Cal Hacks Dashboard or the event Discord.
- Judging format: expo-style science fair. Teams demo at their table to industry professionals,
  engineers, and sponsor judges who walk the floor. Grand prize contenders are selected to pitch
  live on stage at the closing ceremony.
- Sponsor tracks: Anthropic, Amazon, and Fetch.ai are confirmed partners. More APIs, hardware, and
  track requirements are announced at the opening ceremony. Record the tracks you target, and
  each one's exact requirements, in HACK.md.

## What the judging format means for your plan
- Judges arrive mid-demo and leave early. Plan for a 30-second version and a 2-minute version.
- Your table is noisy and judges rotate: the demo must run on one laptop, offline if possible.
- Finalists pitch on stage, so keep a deck that reads from the back of a room (`/hack-showtime`).
- Sponsor judges look for their own API. Make it visible in the journey, not buried in the backend.

## Precedent from the same organizers (not Cal Hacks 13.0 rules)
The UC Berkeley AI Hackathon 2026 (June 20-21, run by the Cal Hacks team,
https://ai-hackathon-2026.devpost.com) worked like this. Plan for the same until told otherwise:
- **Submit before hacking ends.** Projects had to be on Devpost by 11:00 AM; editing stayed open
  until 12:00 PM. Use the submission time, not the end of hacking, as the deadline in HACK.md.
- Every teammate had to be added to the Devpost submission and be an accepted, confirmed hacker.
- A project image and a GitHub repo link were required for code to be considered.
- Teams of up to 4. Code written before the event meant disqualification.
- Sponsor prizes had hard requirements beyond "use our API": a specific product, a social post
  tagging the sponsor, or a separate email. Read each track's text and copy it into HACK.md.
- Anthropic's "Best Use of Claude" asked for projects built with Claude Code on meaningful problems
  (health, education, economic opportunity) and valued ambition over polish. Fetch.ai's asked for an
  agent discoverable through ASI:One that takes real action, "more than a chatbot or a thin wrapper
  around an API."

## Rules that shape scope
- You cannot work on a project started before the hackathon. Ideation beforehand is allowed;
  all implementation happens during the event.
- Open-source libraries, public APIs, and AI coding tools are normal hackathon practice.
  Disclose what you used in your submission, and ask an organizer if you are unsure.

## Judging themes
Based on publicly available Cal Hacks / Devpost judging themes. Confirm the official rubric at kickoff.

| Criterion | The judge's question |
|-----------|----------------------|
| Application | Is it useful in the real world? Who is it for? |
| Functionality / Quality | Does it work smoothly and feel clear? |
| Creativity | Is the approach original or fresh? |
| Technical Complexity | Was there meaningful engineering behind it? |
